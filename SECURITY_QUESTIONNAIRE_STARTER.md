# SAMPLE security questionnaire answer bank (starter)

> Sample / illustrative, for a fictional SaaS company. The rule for every answer: say what is true today, attach the evidence, and give a date for anything planned. Prepared by Kunjar Bhaduri, Bhaduri Advisory, with AI drafting assistance under my direction.

| Question enterprises ask | Answer pattern | Evidence to attach |
|---|---|---|
| Do you have a SOC 2 Type II report? | "Not yet. We are on a track to SOC 2 Type II with [audit firm] and expect the report by [date]. Today we can share our control summary and a recent restore test." | Control summary, restore record |
| How is production access controlled? | "SSO with MFA for all staff; named accounts only; access reviewed quarterly." | Access review record |
| How do you handle backups and disaster recovery? | "Daily backups, retained [N] days; last restore tested on [date], took [X] minutes." | Restore drill record |
| How are changes deployed? | "Every change via pull request, automated tests, peer review and automated deploy with rollback." | CI configuration, sample PR |
| How do you detect and respond to incidents? | "Alerting on customer-facing jobs; on-call rota; written post-incident reviews." | Incident procedure, sample review |
| Is customer data used to train AI models? | State the exact vendor terms and settings. Never guess. | Vendor terms excerpt |
| Where is data stored, and for how long? | Region, retention period, deletion process. | Data retention policy |
